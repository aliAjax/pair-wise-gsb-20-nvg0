# hxwl-06 显微镜玻片观察

样本、多倍率视野与染色观察记录库

## 技术栈

React + Vite + TypeScript + CSS

## 核心规则

- **记录链**：课堂 → 样本 → 观察回合 → 标注逐级关联，每个回合保存前一回合哈希、上下文哈希和确认哈希。
- **回合边界**：老师更换样本、倍率或焦点时开启新回合；同一回合内样本、倍率和焦点固定。
- **倍率失效**：同一样本倍率变化后，上一未确认回合的有效标注标记为 `invalid`，可按倍率换算坐标后补入最新未确认续作回合。
- **确认只读**：老师确认后回合锁定，学生不能直接改写；确认前会检查未同步标注、失效标注和坐标冲突。
- **离线续作**：学生断网补画先进入本地 outbox，回连后按回合和坐标键合并；`clientId` 幂等，重复补传不生成副本。
- **冲突保留**：同坐标出现不同作者或不同值时保留双方值，由老师裁定；确认后的迟到补画进入老师复审队列。
- **失败恢复**：模拟或真实合并失败时保留本地回合和剩余待传坐标，恢复后仅补传缺口。

## 演示能力

- 课堂、样本、观察回合、标注的可续作时间线
- 老师/学生身份切换与在线/断网模拟
- 固定样本、倍率、焦点后开启新回合
- 倍率变化导致标注失效，并按倍率重算坐标
- 回合确认锁定、冲突裁定和确认后补画复审
- 本地 outbox、失败重试、逐坐标幂等合并
- 数据保存在浏览器 `localStorage`，刷新后可继续演示
