# hxwl-06 显微镜观察记录链

课堂 → 样本 → 观察回合 → 标注 的可续作记录链：每个回合固定样本、倍率与焦点，
标注挂在回合上，测量依据不再随换样本/调物镜而错位。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5106

## 逻辑自检

```bash
npm run selfcheck
```

30 项断言覆盖：倍率变化失效重算、确认只读、离线合并、重叠冲突双方留值、
合并失败保留本地、恢复补缺、幂等补传。

## 记录链规则

- **回合固定条件**：开回合时锁定样本、倍率、焦点；标注与测量换算（μm）都绑定该回合条件。
- **倍率变化失效重算**：同样本新开回合倍率不同时，此前回合的未确认标注自动失效并注明原因；
  可一键按倍率比换算后重算到新回合，重新走待确认流程。已确认标注不受影响。
- **确认只读**：老师确认回合后，该回合及其标注只读，拒绝新增与覆盖。
- **断网补画与回连合并**：离线时改动保留在本地（localStorage，刷新可续作）；
  回连后按回合逐坐标合并进课堂服务端（本项目以独立 localStorage 模拟服务端）。
- **重叠冲突**：同一坐标位置出现不同值时，双方值都保留为冲突记录，交老师仲裁
  （采用本地 / 采用远端 / 双方保留）；落败方进入拒绝集，补传不会复活。
- **合并失败与恢复**：回合被他端确认为只读时合并失败，本地回合完整保留；
  老师解锁补录窗口后重试，仅补齐缺失坐标，窗口用后自动重新锁定。
- **幂等补传**：回合与标注均使用稳定 ID，同一回合重复补传不生成副本。

## 演示路径

1. 切「离线」→ 在开放回合的视野画布上点击补画几条标注 → 待同步队列累积。
2. 切「老师」→ 右侧「模拟他端」在相近坐标注入不同值，或「他端确认该回合」。
3. 切回「在线」→ 自动按回合合并：重叠位置产生冲突（双方留值），
   或回合只读导致合并失败（本地保留，老师解锁补录后重试补缺）。
4. 老师在冲突卡片上仲裁；重复点「立即同步」可验证不生成副本。
